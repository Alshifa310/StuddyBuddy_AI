# StuddyBuddy AI — Frontend Portfolio Demo

This branch contains the frontend-only portfolio version of **StuddyBuddy AI**, an AI study assistant originally built with **Next.js** and an **AWS-powered backend**.

The live backend and AI services have been disabled in this version to allow free frontend deployment while still showcasing the chat experience, UI design, responsiveness, and overall user flow.

🔗 **Original Full-Stack Project:**  
<https://github.com/Alshifa310/StuddyBuddy_AI/tree/main>

## Features

* Interactive chatbot UI
* Mock AI responses
* Local chat history
* Responsive design
* Frontend-ready Vercel deployment

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Open:

```txt
http://localhost:3000
```

## Notes

* Backend AI services are disabled in this branch.
* No API keys or AWS setup required.
* Created for portfolio and frontend showcase purposes.
